Parte 4 del Parcial 2
4.1
1. ¿Cuál es la complejidad temporal Big-O?
O(n), porque el ciclo procesa n elementos una vez. Las instrucciones posteriores son constantes y no cambian la complejidad dominante.

2. Si n se duplica, ¿cómo cambia aproximadamente el número de comparaciones?
Justifique su respuesta. No se limite a indicar que existen dos bucles.
Al duplicar n, las iteraciones del ciclo principal aproximadamente se duplican en i y j.

4.2
1. ¿Cuál es la complejidad temporal Big-O?
O(n2), porque la fórmula tiene un término dominante proporcional a n2.

2. Si n se duplica, ¿cómo cambia aproximadamente el número de comparaciones?
Justifique su respuesta. No se limite a indicar que existen dos bucles.

Al duplicar n, las comparaciones para tamaños grandes aumentan aproximadamente cuatro veces.
